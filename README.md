# project-calculator
Project: Calculator from The Odin Project Foundations Course

This is the final project for the Foundations Course, which consolidates all the foundational skills (HTML, CSS, and JavaScript) learned throughout the course.

## Project Requirements

* Create a basic HTML calculator with buttons for each digit and operator (including the equals button).
* The calculator must have a display where numbers and results will be shown.
* The calculator must be functional, performing the four basic operations: addition (+), subtraction (-), multiplication (*), and division (/).
* The calculator should store the values of the numbers and operators input by the user and return the result of the operation.
* The calculator must exhibit expected behavior, including:
    - Handling cases where an operation is called without a number or operator selected.
    - Preventing the addition of leading zeroes if the first digit of the display is already zero.
    - Allowing the decimal point (.) to be entered only once per number.

* Extra credit for the project:
    - Add a decimal (.) button to allow users to    input decimal numbers.
    - Include a 'Backspace' button.
    - Implement keyboard support for calculator functionalities.
